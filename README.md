# 전동현 키우기: 연대기 에디션 — 수정 & 확장 내역

## 1. 버튼이 안 눌리던 원인 (수정 완료)
- `index.html`의 버튼들이 부르는 `enterLocation()`, `forceNextYear()` 함수가
  어떤 파일에도 정의되어 있지 않았습니다.
- `uicontroller.js`가 호출하는 `getAvailableEvent()`, `getLocationName()`도 존재하지 않았습니다.
- `simengine.js`의 `switchHub()`는 존재하지 않는 `activities`라는 전역 변수를 참조하고 있었습니다.
  (실제 이벤트 데이터는 `gamedata.js`의 `yearData[연도].events` 안에 있었습니다.)
- `gameState.dhMoney`, `gameState.actionTurns`가 초기화되어 있지 않아 스탯 계산 중 에러가 났습니다.
→ `simengine.js` / `uicontroller.js` / `gamestate.js`를 새로 짜서 전부 해결했습니다.

## 2. 저장 기능 (새로고침·창 닫기 대응)
- `localStorage`를 이용해 **모든 선택 직후, 연도 전환, 선물/출석/미션 사용 시 자동 저장**됩니다.
- 창을 닫거나 새로고침해도 `beforeunload` 시점에 한 번 더 저장합니다.
- 접속 시 저장 데이터가 있으면 "이어하기 / 새로 시작하기" 팝업이 먼저 뜹니다.
- 엔딩을 보면 그 회차 저장 데이터는 정리되지만, **엔딩 도감(어떤 엔딩을 봤는지)은 별도 키로
  영구 저장**되어 리셋해도 유지됩니다. (우측 메뉴 "📖 일지"에서 확인 가능)
- 우측 상단 💾 아이콘이 저장될 때마다 잠깐 반짝입니다.

## 3. 새 이미지/배경 (파일명 규칙 — 아래 파일만 넣으면 자동 반영)
저는 그림을 직접 생성하는 기능이 없어서 실제 아트는 넣지 못했습니다. 대신 **코드가 아래
파일명을 자동으로 찾도록 연결**해뒀고, 파일이 없어도 기존 이미지로 자연스럽게 대체되어
게임이 깨지지 않습니다 (`images/` 폴더에 넣어주시면 바로 적용됩니다).

| 파일명 | 용도 |
|---|---|
| `images/군복_전동현.png` | 2019~2020년(입대~복무) 동안 캐릭터 이미지로 사용 |
| `images/고시생_전동현.png` | 2022년(노량진 고시생) 동안 캐릭터 이미지로 사용 |
| `images/bg_cafe.png` | 특별만남 - 카페 씬 배경 |
| `images/bg_travel.png` | 특별만남 - 여행 씬 배경 |
| `images/bg_bar.png` | 특별만남 - 술집 씬 배경 |

기존 5개 무드 이미지(고마워하는/부탁하는/슬픈/자존감이 떨어진/자존감이 올라간)는 그대로 유지되고,
위 2개 연도별 이미지는 "그 연도에는 항상 이 모습"으로 우선 적용되도록 로직을 짰습니다
(단, 친밀도가 20 이하로 떨어지면 언제나 슬픈 표정이 우선합니다).

## 4. 티키타카(대화 주고받기) 시스템
기존에는 "상황 제시 → 내 선택 → 바로 결과" 로 끝났습니다.
이제는 **내 선택 → 동현이 반응 → 내 대응 → 동현이 재반응 → 내 대응(2회) → 최종 결과** 흐름입니다.

60개가 넘는 모든 이벤트를 하나하나 손으로 다시 쓰는 대신, **선택의 "온도"에 따라 자동으로
어울리는 대화가 이어지는 엔진**을 만들었습니다(`extradata.js`):
- 선택했을 때의 친밀도/자존감 변화량을 합산해 5단계로 분류: `감동 / 기분좋음 / 애매함 / 서운함 / 빡침`
- 각 단계별로 동현이의 반응 대사 풀(4개)과, 내가 고를 수 있는 후속 대응 풀(5개)을 준비
- 매 턴마다 랜덤하게 조합되어 반복해도 매번 조금씩 다른 대화가 나옵니다
- 후속 대응 선택도 스탯에 소폭 영향을 줘서, 티키타카 자체가 전략의 일부가 됩니다

카톡(chat) 타입 이벤트도 동일하게, 키워드 답장 판정 후 티키타카로 이어집니다.

## 5. 그 외 추가한 재미 요소
- **🌟 특별만남**: 연도당 1회, 카페/여행/술집 중 하나가 배정되는 보너스 장소 (4번 요청 반영)
- **돌발 이벤트**: 일반 장소 이용 후 약 15% 확률로 깜짝 카톡/전화 이벤트 팝업 (턴 소모 없음)
- **관계 호칭 시스템**: 친밀도에 따라 "손절 직전 → 서먹서먹한 사이 → 그냥 아는 사이 →
  편한 형/친구 → 든든한 친형 같은 존재 → 인생 최고의 은인" 으로 호칭이 실시간으로 바뀝니다
- **동현 자산(🪙)**: 기존에 계산만 되고 화면에 안 보이던 `dhMoney` 스탯을 상단바에 노출
- **남은 턴(⏳) 표시**: 전체 게임에 총 32턴의 예산이 있고, 소진되면(또는 자금/친밀도가
  0이 되면) 스탯에 따라 엔딩이 결정됩니다. 연도를 억지로 넘기지 않고 신중하게 장소를
  고르게 만드는 장치입니다
- **📖 일지**: 최근 20개의 선택 기록 + 엔딩 도감(잠금/해제 표시)을 볼 수 있는 모달

## 파일 구성
- `index.html`, `style.css` — 화면/스타일 (저장 표시등, 특별만남 버튼, 일지 버튼, 이어하기 팝업 추가)
- `gamedata.js` — 원래 있던 연도별 스토리 데이터 (내용은 그대로, 손대지 않았습니다)
- `extradata.js` — **신규**: 티키타카 반응 풀, 특별만남 3종, 돌발 이벤트, 신규 이미지 파일명 상수
- `gamestate.js` — 상태값 + 저장/불러오기 + 관계 호칭 + 일지 기록
- `simengine.js` — 게임 엔진 전체 재작성 (버그 수정 + 티키타카 + 특별만남 + 돌발 이벤트)
- `uicontroller.js` — 화면 갱신 + 모달 + 저장/이어하기 흐름 + 일지 모달
